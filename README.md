# Q-SENSE Workshop Website

**Q-SENSE: Workshop on Quantum Sensing Security & Infrastructure Integration**

## GitHub Pages deployment

1. Create a GitHub repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html` and `style.css`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select:
   - Source: Deploy from a branch
   - Branch: `main`
   - Folder: `/ (root)`
5. Save. The site will be available at `https://YOUR-USERNAME.github.io/`.

## Before publishing

Replace or add:
- Workshop year/date
- Venue
- Submission deadline
- Notification date
- Camera-ready deadline
- Actual Microsoft CMT submission URL
- Contact email
- Any DATE-specific submission-format requirements

The current site intentionally does not invent dates, venue, or a contact email.
